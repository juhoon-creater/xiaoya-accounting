# 小芽记账 App 第一版规格

## 第一版功能

### 1. 用户账号

- 用户名和密码注册。
- 用户名不可重复。
- 用户名和密码登录。
- 用户退出登录。
- 密码使用 BCrypt 加密后保存，不保存明文密码。
- 登录成功后使用 Token 访问后端接口。
- 第一版不使用手机号、短信验证码和第三方登录。

### 2. 账单管理

- 新增收入或支出账单。
- 查询当前用户的账单列表。
- 查看单条账单详情。
- 修改账单。
- 删除账单。
- 按月份查询账单。
- 按收入/支出类型筛选账单。
- 按账单分类筛选账单。
- 账单列表分页查询。
- 每笔账单包含：金额、收入/支出类型、分类、记账日期、备注、创建时间和更新时间。
- 金额必须大于 0。
- 用户只能查询和操作自己的账单。

### 3. 账单分类

- 提供默认支出分类：餐饮、交通、购物、娱乐、学习、医疗、住房、其他。
- 提供默认收入分类：工资、奖金、兼职、报销、其他。
- 第一版使用系统默认分类，不支持用户自定义分类。

### 4. 预算管理

- 设置指定月份的总预算。
- 设置指定月份的分类预算。
- 查询指定月份的总预算和分类预算。
- 显示总预算已使用金额、剩余金额和使用比例。
- 显示各分类预算已使用金额、剩余金额和使用比例。
- 预算使用情况由后端根据真实账单计算。

### 5. 月度统计

- 查询指定月份的总收入。
- 查询指定月份的总支出。
- 查询指定月份的收支结余。
- 查询各分类的支出金额和占比。
- 查询当月账单数量。
- 所有统计结果由后端根据 MySQL 中的当前用户账单计算。

### 6. 第一版不实现

- AI 助手。
- 语音记账。
- OCR 或账单截图识别。
- 手机号和短信验证码登录。
- 银行、微信或支付宝账单自动同步。
- 多账本。
- 存钱目标。
- 自动续费提醒。
- Web 管理中台。
